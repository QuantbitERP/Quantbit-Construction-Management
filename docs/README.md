# Quantbit Construction Management — Documentation

This directory contains the complete technical documentation for the **Quantbit Construction Management** Frappe app — a construction project management layer built on top of ERPNext. Every statement in this documentation set is traceable to source code in this repository; where something could not be confirmed, it is explicitly marked **"Not found in repository"** rather than guessed.

## Start Here

- **New to the app?** Read [`project-overview.md`](project-overview.md) first, then [`architecture.md`](architecture.md).
- **Setting up a dev environment?** Go to [`installation.md`](installation.md) → [`configuration.md`](configuration.md).
- **Looking for a specific DocType, API, or report?** Jump straight to [`doctypes.md`](doctypes.md), [`api-reference.md`](api-reference.md), or [`reports.md`](reports.md).
- **About to write code?** Read [`developer-guide.md`](developer-guide.md) and [`coding-guidelines.md`](coding-guidelines.md).
- **Debugging something?** Check [`troubleshooting.md`](troubleshooting.md) and [`known-limitations.md`](known-limitations.md) first.

## How This Documentation Was Produced

This documentation was generated by directly reading the application's source code — every DocType's `.json`/`.py`/`.js` files, `hooks.py`, `pyproject.toml`, fixtures, reports, and client scripts — rather than inferring behavior from naming conventions alone. Every claim is anchored to a specific file (and where useful, a line number). If you find something here that no longer matches the code, the code is authoritative — please update the relevant doc alongside your change (see [`developer-guide.md`](developer-guide.md)).
